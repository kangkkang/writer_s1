# 미결정 사항

**항목 번호는 기존 막별 관리 식별자이며 권 번호가 아니다.** 실제 적용 시점은 표의 필요 시점을, 권·막 대응은 `30-플롯-전체지도.md`를 따른다.

**현재 열린 항목은 아래 10건이다.** 본문에 필요해지면 임의로 확정하지 말고 작가에게 묻는다. 과거 결정 과정과 기각안은 `../history/결정기록.md`에 보관한다.

| 번호 | 결정할 것 | 판단에 필요한 맥락 | 필요 시점 |
|---|---|---|---|
| 1-1 | 카일이 쓰는 인쇄 학술 정오표의 구체적 매체와 응답 문안 | 오프라인 암호문 → 종이 교정쇄의 키 위치 단서 → 복호화 → 인쇄 정오표로 첫 응답 → 약 8개월 뒤 합류까지는 확정. 실제 인쇄·배포 주기와 누가 그 교정란을 확인할 수 있는지 장면 수준에서 맞춰야 한다. 신문 광고는 훗날 클레망스 접선에만 쓴다. | 1막 비트 2·5 |
| 1-2 | 클레망스의 비공개 수면다원검사 자료 보관 지점을 이단이 발견·접근하는 방식 | 장소의 비밀만으로 진위를 보장하지 않는다. 미공개 시각·송출 로그와 새 질의 응답으로 확인하는 절차는 확정했으나, 목적지를 찾고 메시지를 남기는 구체적 수단은 남아 있다. | 1막 비트 5 |
| 1-6 | 수면 웰니스 브랜드명과 공개 층 열 개의 이름 | 교단의 표면 브랜드, 원형 밴드·스마트 침구·수면 클리닉 운영, 층이 오를수록 노출 강도 상승, 공개 층은 번호 없이 이름으로 부른다는 것은 확정(→ `11-교단.md`). 이름이 '열한 번째'나 차원 번호를 암시하지 않아야 한다. | 1막 비트 3 |
| 1-7 | 11층의 초대 경로와 참가자 규모 | 비공개 비등록 연구, 칩 식립, 최초 참가자는 문지기 둘이라는 것은 확정. 고객이 어떻게 초대받는지와 대략의 인원은 미정이다. 규모 숫자를 본문에 쓰지 않는 방침은 유지한다. | 1막 비트 3 |
| 1-8 | 이단의 디지털 시험 장면 설계 | 원격 관찰, 근접 위기 없음, 계정 연동 접속에는 사람이 오고 익명 공공 단말에는 오지 않는다는 결론, 시험마다 지역이 드러나는 대가는 확정(→ `31-플롯-막별.md` 비트 2). 시험 횟수·장소·도착까지의 시간은 장면 설계 때 정한다. | 1막 비트 2 |
| 1-4 | 첫 앵커 발발·홀트 자기 종료 때 두 사람의 탈출 동선 | 홀트의 사전 종료 조건과 자발적 죽음은 확정. 요원의 제거 시도가 재난으로 끊기고 두 사람이 침입 때 확보한 경로와 기지로 탈출하는 방향은 확정했으나, 제압을 벗어나는 동작과 손상 영역·대피 경로의 위치 관계는 장면 설계가 남아 있다. | 1막 비트 7 |
| 1-5 | 시냅스 신임 부회장의 공적 배경과 취임 뉴스 세부 | 탈출 며칠 뒤 홀트 실종 뉴스, 그 뒤 시간 경과 후 신임 부회장 취임 연설을 이단과 클레망스가 함께 시청하는 것은 확정. 이름은 `10-인물.md`에 확정했으며, 공적 배경·취임까지의 정확한 시차·연설 문안은 미정이다. 기업 직위의 승계이며 추가 지도부 조각이나 홀트 복제를 확정하지 않는다. | 2막 도입 |
| 3-1 | 아브람 라이스너의 최후 | 1막에서는 크로울리에게 닿는 중개자다. 3막 미궁의 정산에서 어떻게 처리할지 정해야 한다. | 3막 |
| 4-2 | 정렬 창 예고의 오차 폭과 발사 중단 기준 | 관측 신호는 '단면'(발신망 간섭 관측의 수렴)으로 확정했다(→ `21-과학설정.md` 5절). 모듈라이 이동과 지상 발신망의 위상이 맞는 창은 4막에 한 번뿐이고, 인간 상태 슬롯은 하나다. 수렴을 어디까지 확인해야 발사하는지, 오차 폭과 중단 기준은 장면 설계 때 정한다. 65% 전력·50% 정밀 산업은 작품 속 계획값이며 현실의 임계값이 아니다. | 4막 블록 1·5 |
| 4-3 | 프로토타입 응급 결합의 세부 계측·안전장치 | 전송 전 모의 귀속의 역위상 응답, 전송 뒤 이단의 실제 귀속 감시, 클레망스의 사전 작동과 붕괴 순간 자동 결합은 확정. 정확한 계측 파형·짧은 포착 창의 길이·위험한 자기 신경 결합을 허용하는 물리적 조작 절차는 미정이다. 정상적인 두 번째 전송 수단으로 만들지 않는다. | 4막 블록 3 복선 배치 전·5막 블록 2 |

5-1·5-4의 확정 내용은 `10-인물.md`, 5-3은 `21-과학설정.md` 6절, 5-5는 `22-프로메테우스.md` 4절, 5-6·5-7은 `23-외계-본체.md` 4절에 반영했다. 이곳에 결론을 복제하지 않는다.

방화벽 전환과 물리적 존속에 관한 2-1·3-2는 `21-과학설정.md` 4절, 사전 장비는 `22-프로메테우스.md` 3절, 구현 책임은 `11-교단.md`, 사건·해금 순서는 `30-플롯-전체지도.md`·`31-플롯-막별.md`에 반영했다.

시냅스 진입·홀트 대면의 기존 1-3은 `31-플롯-막별.md` 1막에 반영했다. 국소 초기화·계측 파일은 `22-프로메테우스.md`, 현장 강압의 예외는 `11-교단.md`·`../Claude.md`를 따른다.

홀트의 종료 조건·자발적 죽음은 `11-교단.md`, 실종·후임 취임 뉴스는 `31-플롯-막별.md`, 공개 시점은 `30-플롯-전체지도.md`에 반영했다. 기존 1-4의 사망 예측 실패·데이터 변조 논의는 종료했고, 해당 행에는 미정인 탈출 동선만 남겼다.
