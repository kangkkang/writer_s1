# 복선대장

재독 때 의미가 바뀌는 장면의 목록이다. **설정 자체는 여기 적지 않는다** — 정본은 '근거' 칸의 파일이다. 이 문서는 어디에 심고 언제 거두는지만 관리한다. 정보가 독자에게 공개되는 순서 전체는 `30-전체지도.md` 정보 해금 대장을 따른다.

- **ID**: `F` + 두 자리. 지운 복선의 번호는 다시 쓰지 않는다.
- **최초 등장**: 막·비트/블록. 원고가 생기면 장 번호(`manuscript/` 전체 일련번호)를 덧붙인다.
- **상태**: 설계 → 심음(장 번호) → 회수(장 번호). 버리면 '폐기'로 두고 사유를 한 줄 남긴다.
- 새 복선을 만들 때 표면적 의미가 1~3막의 해금 순서를 앞당기지 않는지 `30-전체지도.md`로 확인한다.
