# 검토 보고

정합성 교차 검증과 원고 검수의 결과를 남긴다. **정본이 아니다** — 판정에 따라 고친 결론은 `canon/`·`plot/`에 있고, 여기에는 무엇을 왜 지적했는지만 남는다.

- 파일명: `YYYY-MM-DD-주제.md`. 검증할 때마다 한 파일을 만든다.
- 파일 안을 **과학 / 연속성 / 인물** 절로 나눈다. 해당 없는 절은 생략한다.
- 지적마다 `파일:라인` 근거, 심각도(치명·중대·경미), 판정(유지·기각·조정), 반영 여부를 적는다. 라인 번호는 검토 당시 기준이므로 이후 수정으로 어긋날 수 있다.
- 원고 검수는 장 번호(`manuscript/` 일련번호)를 붙인다.
