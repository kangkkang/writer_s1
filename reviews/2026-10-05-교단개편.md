# 2026-10-05 교단 개편 교차 검증

**범위**: 교단 개편(신도 없는 소수 교단, 수면 웰니스 브랜드 표면)과 매개 찾기 구조(아이디어 3·4·6·9·10) 채택안.
**방식**: 조사 에이전트 1라운드 → 반박 검토 에이전트 2라운드, 둘 다 읽기 전용. 판정은 주 에이전트가 원문을 재확인해 내렸다. 반영 뒤 별도 검토 에이전트로 수정본을 한 번 더 점검했다.
**라인 번호는 검토 당시(구 파일명) 기준이다.** 파일명 대응: 21=`21-과학`, 23=`23-외계본체`, 30=`plot/30-전체지도`, 31=`plot/31-막별`, 99=`plot/99-미결정사항`.

## 결과 요약

| 판정 | 처리 |
|---|---|
| 지도부 6인 전원 칩(마이크 고백 순간 즉사, 홀트 잔해의 칩) | 작가 결정으로 **문지기** 직책 신설, 부교주 3인으로 축소. 마이크·홀트는 칩·11층 기록 없음 |
| 공개 '야간 보정'이 비트 7 강탈 예외를 무너뜨림 | '야간 동조'로 개칭, 근사 정렬·정확값 아래 포화 |
| 정수 구역이 5막 첫 증명의 반증 재료 | 폐기 |
| 1~10층 번호가 11차원을 조기 연결 | 처음엔 이름 층으로 반영했으나, 작가 판단으로 **1층~10층 번호 채택**. 이단 시점에서 11에 머무르지 않는 금지선만 유지 |
| 해부 제물·마을 몰살, 클레망스 수배 | 작가 결정으로 폐지. 불면 사망, '사라진 조회자'로 대체 |
| 측정이 문을 연다의 4·5막 확장 | 1~3막 앵커 위치 확률로 한정 |

## 과학

- 대역폭 단조 증가(구 22:45)와 "수면 시간대 개방"의 충돌 → 밤에 쌓이는 것은 학습 입력으로 정리.
- 선취 흔적: 집행이 통로 없이 진행된다는 규칙(구 22:214)과의 경로 → 임계 이후 매개변수 집행 계산의 부산물로 한정. 2막 앵커에는 없음.
- 불면 사망: 인간이 며칠 만에 수면 박탈로 죽은 기록은 없고 치명적 가족성 불면증은 수개월 이상 진행 → 급성 기전을 작품 고유 설정(정렬 수렴 자율신경 실조)으로 명시.
- [FACT 오류, 기존] WHO는 임상시험 승인 기관이 아님 → 로드리게스 역할 수정.
- '접속 비용', '선취 흔적', '단면'에 작품 고유 가정 표시 추가.

## 연속성

- 교주 고지 조각의 출처(구 31:72 공개 교리) → 팬덤 공개 전승으로 교체.
- 마이크 복선 금지선(구 30:195) 위반 후보("수면 로그부터 보자", 4막 수면 질문) → 삭제.
- 2막에 다섯을 모두 안다고 쓴 해금 순서 오류 → "1~3막에 차례로 드러나는 다섯".
- 정밀 계측 경향의 인지 시점(2막 의심 vs 해금 대장 3막) → 3막으로 통일.
- 카일 감시와 이단의 체류 시점, 클레망스가 1막에 살아남는 이유, 광고 해독 근거, 암살 실패 횟수 기준 → 각각 한두 문장으로 명시.

## 인물

- 바이스가 팬덤 의식을 '주도'하면 지시 계통이 생김 → 팬덤이 스스로 연 의식에서 설교하던 중 사멸.
- 문지기가 11층 최초 참가자인데 급사하지 않는 이유 → 고노출을 받지 않음, 노출 강도는 지도부가 정함.
- 이단이 밴드 사용자였다면 기기를 버린 순간 반동 불면 → 비사용자로 확정.
